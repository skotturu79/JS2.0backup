The Warehouse Operations Challenge

SAP EWM · S/4HANA
🏭

Transaction-Driven Operations

Warehouse staff navigate 10+ SAP transactions (LT01, MB51, MIGO, LI01…) to answer basic questions about stock, orders, and deliveries — every time.

🔍

No Cross-Domain Visibility

EWM bin stock, MM inventory, production orders, and inbound deliveries live in different system contexts with no unified conversational view.

⏱️

Manual, Time-Consuming Actions

Goods receipts, task confirmations, and stock transfers require SAPGUI access and multiple form steps — even for routine, repetitive operations.

📱

No Lightweight Interface

Shop floor workers cannot quickly query bin stock or confirm warehouse tasks without full SAP GUI access on a desktop workstation.

🔗

Joule EWM Coverage Gap

SAP Joule lacks deep EWM warehouse operations — bin-level stock, task management, HU-level GR, and goods movement actions are absent from the standard skill set.

🤖

AI Projects Take Too Long

Traditional AI for warehouse ops takes 8–12 months and rare SAP + ML specialists. Every new backend or use case starts from scratch with no reusable framework.

→ Open LX03, navigate warehouse/bin, read screen manually
"Which inbound deliveries are expected today for PBAR?"
→ Run VL06I, filter by warehouse, export to Excel
"Confirm warehouse task 1000045 to bin GR-DOCK with 50 EA"
→ Navigate LT12, enter task + quantities + bin, confirm
"Post goods receipt for inbound delivery 180000234"
→ Open MIGO, select GR for inbound delivery, fill items, post
"Status of production order 1001176 — any shortages?"
→ CO03, multiple tabs, manual component availability check

→ [Confirmation prompt] → User approves → "Task 1000045 confirmed. 50 EA → GR-DOCK."

→ [Shows items, asks confirmation] → "GR posted. Material document 5000012345 created."

Floating Desktop Widget

Transparent tkinter overlay for Windows — stays visible while SAP GUI is open. Ctrl+Alt+W shows/hides from anywhere. Ctrl+Alt+J opens popup and switches destination to D4H-200. Auto-launches at Windows login via Startup folder.

floating_icon.pyw · pythonw.exe · shell:startup

MCP Proxy (Joule Desktop / Claude Code)

FastAPI server on localhost:8766 exposing ask_warehouse_agent as a single MCP tool over Streamable HTTP (MCP 2025-03-26). Register in Joule Desktop, Claude Code (.mcp.json), or Cursor without browser authentication.

http://localhost:8766/mcp · mcp_proxy/warehouse_mcp.py
